# Smart Campus Route Optimizer

A C++ based web application that finds the shortest routes between different locations on a college campus using Dijkstra's Shortest Path Algorithm.

## Live Website
[Visit Smart Campus Route Optimizer](https://saisha774.github.io/Smart-Campus-Route-Optimizer/)

## Features
- Find the shortest route between campus locations.
- Calculate estimated walking distance and time.
- Search campus locations.
- Find the nearest location.
- Block and unblock roads dynamically.
- View and clear route history.

## Technologies Used
- C++
- Data Structures and Algorithms
- Dijkstra's Shortest Path Algorithm
- Priority Queue
- Graphs and Adjacency Lists
- WebAssembly
- HTML
- CSS
- JavaScript

## How It Works
The campus is represented as a weighted graph. Dijkstra's algorithm calculates the shortest path between the selected source and destination. The C++ backend is compiled into WebAssembly to run in the browser.

## Project Objective
To provide an efficient navigation solution that helps students and visitors find optimal routes between different locations on a college campus.
